# 🛒 Amazon Clone (Frontend Project)

## 📌 Project Overview

This project is a **frontend clone of the Amazon homepage** built using **HTML5 and CSS3**. It replicates the layout and design of Amazon’s landing page, including the navigation bar, search bar, product sections, and footer.

The main goal of this project is to practice **web design, layout structuring, and responsive UI development**.

---

## 🚀 Features

* 🧭 Navigation bar with logo, search bar, and cart
* 📍 Delivery location section
* 🔍 Search functionality UI
* 🛍️ Product grid layout (multiple categories)
* 🎯 Hero section with promotional message
* 📦 Multiple product boxes (laptop, phone, clothes, etc.)
* 📄 Footer with useful links
* 🎨 Styled using CSS for a clean UI

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and layout
* **Font Awesome** – Icons (cart, location, search, etc.)
